# Estilos con CSS

CSS (Cascading Style Sheets) controla cómo se ve tu página: colores, tamaños, posiciones.

## Ejemplo

```css
body {
  background-color: #fef3c7;
  font-family: Arial, sans-serif;
}

h1 {
  color: #7c3aed;
  text-transform: uppercase;
}
```

## Actividad

1. Creá un archivo `styles.css`.
2. Vinculalo en tu HTML con `<link rel="stylesheet" href="styles.css">`.
3. Cambiá colores y tamaños.

## Desafío

Hacé que tu página tenga un diseño brutalista: bordes negros, sombras duras y colores planos.
