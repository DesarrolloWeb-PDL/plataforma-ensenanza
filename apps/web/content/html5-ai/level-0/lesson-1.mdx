# Tu primera página web

HTML es el lenguaje que estructura las páginas web. Toda página tiene una estructura básica.

## Estructura básica

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola mundo</h1>
    <p>Esta es mi primera página.</p>
  </body>
</html>
```

## Actividad

1. Creá un archivo `index.html`.
2. Copiá la estructura de arriba.
3. Abrí el archivo en el navegador.

## Desafío

Agregá una imagen y un enlace a tu página.
