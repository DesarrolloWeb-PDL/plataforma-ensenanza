# Interactividad con JavaScript

JavaScript permite que tu página reaccione a acciones del usuario: clics, teclas, formularios.

## Ejemplo

```html
<button onclick="saludar()">Saludar</button>
<script>
  function saludar() {
    alert("¡Hola!");
  }
</script>
```

## Actividad

1. Agregá un botón a tu página.
2. Vinculá una función JavaScript al clic.
3. Probá cambiar el texto de un párrafo al hacer clic.

## Desafío

Creá un contador que aumente y disminuya con dos botones.
