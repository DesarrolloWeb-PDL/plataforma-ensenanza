# Vocabulario de bloques en inglés

En el mundo de la programación se usa mucho el inglés. Vamos a aprender los términos más importantes.

## Vocabulario

| Inglés | Español |
|---|---|
| Block | Bloque |
| Script | Guión / Script |
| Stage | Escenario |
| Sprite | Personaje |
| Motion | Movimiento |
| Looks | Apariencia |
| Sound | Sonido |
| Events | Eventos |
| Control | Control |
| Flag | Bandera |

## Actividad

1. Leé cada término en inglés.
2. Decí en voz alta su significado en español.
3. Jugá a emparejar: escribí la columna en inglés y traducila.

## Desafío

Creá una lista con 5 términos nuevos que hayas aprendido.
