# Quiz de inglés web

Respondé para comprobar lo aprendido.

## Preguntas

1. **"Tag"** significa:
   - a) Etiqueta
   - b) Función
   - c) Variable

2. Completá: "Click the __________ to submit the form." (button)

3. **"Function"** se traduce como:
   - a) Clase
   - b) Función
   - c) Evento

4. Traducí: "Add a new attribute to the link."

5. **"Browser"** es:
   - a) Servidor
   - b) Navegador
   - c) Estilo

## Respuestas

1. a) Etiqueta
2. button
3. b) Función
4. Agregá un nuevo atributo al enlace.
5. b) Navegador
