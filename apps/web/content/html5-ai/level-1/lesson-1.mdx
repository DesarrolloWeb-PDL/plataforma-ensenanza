# Vocabulario web en inglés

En desarrollo web, casi todo el vocabulario está en inglés. Vamos a aprender los más importantes.

## Vocabulario

| Inglés | Español |
|---|---|
| Tag | Etiqueta |
| Element | Elemento |
| Attribute | Atributo |
| Style | Estilo |
| Select | Selector |
| Function | Función |
| Variable | Variable |
| Event | Evento |
| Button | Botón |
| Link | Enlace |
| Class | Clase |
| ID | Identificador |

## Actividad

1. Leé el término en inglés.
2. Decí su significado en español.
3. Escribí un ejemplo: `<button>` → botón.

## Desafío

Etiquetá 5 elementos de una página web con su nombre en inglés.
