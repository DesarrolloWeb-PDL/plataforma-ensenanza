# Frases técnicas en inglés

Estas frases verás mucho en tutoriales y documentación en inglés.

## Lecturas

1. **"Add a class to the element."**
   → Agregá una clase al elemento.

2. **"Call the function when the button is clicked."**
   → Llamá a la función cuando se haga clic en el botón.

3. **"Change the color to blue."**
   → Cambiá el color a azul.

4. **"The page loads in the browser."**
   → La página se carga en el navegador.

## Actividad

1. Leé cada frase en inglés.
2. Traducila al español.
3. Explicá qué haría ese código.

## Desafío

Escribí 3 instrucciones en inglés para estilar un botón.
