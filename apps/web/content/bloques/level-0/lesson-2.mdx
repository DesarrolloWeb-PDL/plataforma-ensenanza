# Secuencias básicas

Un programa es una secuencia de instrucciones que se ejecutan en orden.

## Actividad

1. Creá una secuencia: **mover**, **girar**, **mover**.
2. Cambiá el orden y observá cómo cambia el resultado.

## Concepto clave

El orden importa: si cambiás la secuencia, el personaje hace cosas distintas.

## Desafío

Hacé que el personaje dibuje una letra (por ejemplo, una L).
